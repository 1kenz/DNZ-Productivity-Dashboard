Standalone Native macOS Experience

Zero Docker Needed. Bundled With Embedded PostgreSQL.

The standalone macOS desktop app (.dmg) packages everything into a native Apple Silicon app. It automatically spawns an embedded PostgreSQL 17 instance on boot, mounts a macOS Menu Bar (Tray) icon for instant access, and registers global hotkeys like Cmd+K and Cmd+J.

  • Embedded Postgres 17: Starts in milliseconds without external daemons.
  • macOS Menu Bar Tray: Quick actions, Pomodoro toggle, and instant notes.
  • Offline First: Complete autonomy even with no internet access.

bash scripts/build_desktop_app.sh

Security & Privacy First

Unlike proprietary SaaS tools that scrape your tasks and calendars for model training, DNZ Productivity Dashboard is 100% local-first. Your data resides entirely inside your local PostgreSQL database. No telemetry, no third-party trackers, and no external calls unless you explicitly configure Google Drive Sync or provide your own AI API keys.

Quickstart & Installation

Get up and running in under two minutes with Docker or npm.

1 Run via Docker Compose (Recommended)

# 1. Clone repository
git clone https://github.com/1kenz/DNZ-Productivity-Dashboard.git
cd dnz-productivity-dashboard
# 2. Copy environment template
cp .env.example .env
# 3. Start database and web application
docker compose up -d

Open http://localhost:3000 to access the dashboard.

2 Local Development (Node 18+)

# Install dependencies
npm install
# Push Prisma schema to local PostgreSQL
npx prisma db push
# Start Next.js development server
npm run dev
